# Vantheon

Small team. Independent projects. Built with care.

Vantheon is a small, independent software and engineering effort. We make things because we're curious about how they work, because existing tools don't always do what we need, and because building something useful is worth the effort.

We're early. Our community is small, our resources are limited, and most of the work is done by a very small number of people. We don't want to pretend otherwise. We'd rather be open about where we are, keep improving, and earn people's trust through the things we actually ship.

What we're working on

Our current work is centred around the Vanta projects:

- "Vanta Launcher" (https://github.com/ItsDropper/Vanta) — a Minecraft launcher focused on making instances and modded setups easier to manage, including support for a broad range of loaders.
- "VantaLoader" (https://github.com/ItsDropper/VantaLoader) — an independent mod-loading project exploring an alternative approach to the Minecraft modding ecosystem.
- "Vanta Client" (https://github.com/ItsDropper/Vanta-Client) — client-side tools and features built around the Vanta ecosystem.
- "VantaOS" (https://github.com/ItsDropper/VantaOS) — an ongoing operating-system project and a place to learn by working on lower-level systems engineering.

These projects are works in progress. Features, compatibility and stability can vary between releases, so please check each project's documentation and release notes before relying on them.

How we work

- Useful over flashy. We'd rather solve a real problem than announce a feature that isn't ready.
- Honest about progress. Experimental means experimental. If something is unfinished or has limitations, we'll say so.
- Open to feedback. Bug reports, thoughtful criticism, ideas and contributions are welcome.
- Respect for users. We aim to make software that is understandable, maintainable and respectful of the people using it.
- Learn in public. Not every experiment will work. We treat mistakes as part of engineering, document what we learn, and keep moving.

Get involved

You don't need to be an expert or a long-time contributor to be helpful.

- Found a bug? Open an issue in the relevant repository with steps to reproduce it.
- Have an idea? Start a discussion or issue and explain the problem it would solve.
- Want to contribute? Check the repository's contribution guidance first, then open a pull request.
- Just trying something out? That's welcome too. Useful feedback from someone using a project for the first time can be especially valuable.

Please be respectful when interacting with maintainers and other contributors. We'll do our best to be respectful of your time in return.

A note about where we are

Vantheon is still growing. We don't have a large team, a big budget or a polished answer to every problem. What we do have is the willingness to learn, build carefully and keep showing up.

If something here interests you, take a look around. If it doesn't, that's fine too. Thanks for giving our work a moment of your time.
